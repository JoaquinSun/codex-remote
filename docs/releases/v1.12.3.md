# Codex Remote Server v1.12.3

版本：**1.12.3（build 15）**。本次发布包含网页版图片拖入、项目列表稳定性修复，以及自 v1.0.0 以来的桌面会话连接和用量展示改进。

## 新增功能

- 在打开的网页聊天中，直接将一张或多张图片拖入页面，预览后发送；附件可以移除，每条消息最多六张图片。
- 连续拖入图片与文件选择器共用附件数量限制；切换聊天会取消仍在读取的图片，取消拖拽会清除提示。
- 侧边栏显示正在工作的项目、运行中的聊天数量与待审批状态。
- 网页和 macOS 主窗口增加 Codex 额度与 CC Switch 今日用量概览。
- 进度、思考、计划和回答按原顺序显示；连续命令、工具调用与文件改动仍可展开查看。

## 修复

- 项目分组与正在工作的项目入口保持项目目录顺序，其他项目的聊天更新不会使列表反复跳动；两个侧栏列表保留滚动位置。
- 手机发送的文本补齐桌面消息所需字段，修复桌面聊天页面崩溃；引导消息携带恢复消息信息，修复读取 `cwd` 的异常。
- 普通持久化聊天通过 ChatGPT 本地接口读取和操作，消息发送、引导、中断和审批由聊天所属的桌面窗口处理。
- 默认聊天数据 socket 缺失或拒绝连接时，自动恢复共享数据服务；显式指定自定义 socket 时沿用用户配置。
- 支持已验证的 ChatGPT 桌面状态协议 13，同时保留协议 11 兼容处理。
- 模型和权限设置在新一轮开始前由桌面确认；引导沿用当前轮设置，未确认的提交不会重复发送。

## 下载与使用

1. 下载 `CodexRemoteServer-1.12.3-macOS-arm64.zip`，解压后将 `Codex Remote Server.app` 放入「应用程序」。
2. 需要 Apple Silicon（M 系列）Mac、macOS 14 或更高版本，以及已登录且可使用 Codex 的 ChatGPT 桌面 App。
3. 需要 Node.js 18 或更高版本；App 也会检测桌面 App 自带的 Node 运行时。桥接源码已包含在 App 内。
4. 启动服务，将接入地址复制到手机浏览器；设备需处于同一局域网或接入 Tailscale。
5. 打开聊天后可直接拖入图片。升级后刷新已打开的网页，即可加载新版界面。

下载包使用临时签名，未经过 Apple 公证。首次打开时，macOS 可能要求在「系统设置 → 隐私与安全性」中确认。
同时提供 `SHA256SUMS.txt`，用于核对 ZIP 的 SHA-256 校验值。

## 兼容说明

- 下载包为 arm64，适用于 Apple Silicon Mac。
- 桌面本地 IPC 是内部接口，已验证 ChatGPT `26.1111.21308`；未来桌面更新可能需要相应适配。
- 普通聊天由 ChatGPT 桌面执行；临时聊天沿用数据服务的内存会话。
- 实际模型与额度取决于本机登录方式和模型服务。CC Switch 未安装或用量接口不可用时，相应卡片显示不可用状态。
