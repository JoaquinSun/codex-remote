# Codex Remote Server v1.0.0

首个 macOS App 发行版，基于 [KotChiu/codex-remote](https://github.com/KotChiu/codex-remote) 开发，保留上游 Git 历史。
由 [JoaquinSun/codex-remote](https://github.com/JoaquinSun/codex-remote) 维护，与 OpenAI 无隶属关系。

## 下载与使用

1. 下载 `CodexRemoteServer-1.0.0-macOS-arm64.zip`，解压后将 `Codex Remote Server.app` 放入「应用程序」。
2. 需要 Apple Silicon（M 系列）Mac、macOS 14 或更高版本、已安装并登录的 Codex 桌面 App，以及 Node.js 18+
   （或 Codex 自带的 Node 运行时）。App 包含桥接源码，Node.js 使用本机安装的运行时。
3. 打开 App，在主窗口启动服务，复制接入地址到手机浏览器。手机和 Mac 需在同一局域网或接入 Tailscale。
4. 设置直接在主窗口内展开；齿轮、菜单栏「设置」和 `⌘,` 均指向同一区域。

App 使用临时签名，未经过 Apple 公证；首次打开时，macOS 可能需要在「系统设置 → 隐私与安全性」中确认。
下载包旁附有 `SHA256SUMS.txt`，用于校验 ZIP 文件。

## 新增功能

- macOS 原生管理界面、菜单栏入口、启动 / 停止 / 重启、运行状态与日志、登录启动和防休眠选项。
- 按会话选择模型与思考强度，选项读取当前 Codex 模型列表，选择从下一轮开始生效。
- 接近 Codex 的消息展示：主要回答保持可见，思考、命令、工具调用与文件改动默认收进可展开的执行过程。
- 新版深浅主题、SVG 控件、手机布局、会话搜索与 `⌘K` / `Ctrl+K`。
- 使用可复制的接入地址连接设备，已移除二维码功能。

## 修复

- 服务重启后恢复运行状态，重启失败时仍可继续操作。
- 仅本机监听只提供本机地址；修改端口和监听范围后，接入地址在重启成功后更新。
- 旧进程退出回调不会清除新进程的状态。
- 收起桌面侧边栏后，搜索快捷键会先展开侧边栏并聚焦搜索框。

## 验证

- Node 回归测试与 macOS 客户端回归测试通过。
- 模型设置、消息流式更新、手机布局、搜索快捷键及主窗口内设置已通过隔离会话 / 演示界面验证。
- App 构建和签名校验通过。桥接版本为 `1.10.1`。

## 兼容说明

- 本次下载包为 **arm64**，适用于 Apple Silicon Mac。
- 已有 launchd 桥接服务时，App 会显示为外部进程托管；通过原来的部署方式管理该服务。
- 实际可用模型和推理权限取决于当前 Codex 安装、账号与模型服务。
